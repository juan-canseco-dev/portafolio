GameHub

Multi-channel chat application built with ASP.NET Core and Blazor, combining real-time communication, JWT authentication, and asynchronous messaging within Clean Architecture.

Live demo in progress

Project Overview

GameHub is a multi-channel chat application built with ASP.NET Core and Blazor WebAssembly. It combines JWT authentication with real-time communication through SignalR and Redis Backplane, integrating backend services with an interactive frontend.

The backend uses Clean Architecture and a CQRS-style flow to separate responsibilities and organize application operations. Asynchronous messaging uses RabbitMQ and MassTransit, while data persistence uses SQL Server and Entity Framework Core.

I added automated tests with xUnit and Testcontainers to validate application behavior. The project brings together authentication, persistence, and messaging, with an emphasis on maintainability and separation of responsibilities.
