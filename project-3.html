Sistema de Horarios

Desktop application developed and delivered for a secondary school using C#, .NET, Windows Forms, and SQLite, with academic data management and scheduling conflict prevention.

Live demo in progress

Project Overview

Sistema de Horarios is a desktop application I developed for a secondary school using C#, .NET, and Windows Forms. It manages teachers, subjects, groups, classrooms, and weekly timetables, with data stored in SQLite.

The system includes algorithms to prevent scheduling conflicts, supporting the organization of weekly academic activities. It was completed and delivered to address a real school scheduling need.

The project uses a layered architecture and dependency injection. Delivering it helped me better understand the relationship between scheduling rules, data persistence, and the user workflow, and informed my approach to separating responsibilities in later projects.
